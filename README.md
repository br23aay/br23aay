## 🚀 Featured Projects

### 🦾 [Shadow Hand Dexterous Manipulation — PPO](https://github.com/br23aay/shadowhand-dexterity-ppo) · *Published Research*
> Trained a **24-DoF Shadow Dexterous Hand** in MuJoCo using Proximal Policy Optimisation to perform in-hand pen manipulation with human-like precision.

- 🎯 **175° pen rotation achieved** | 97.2% target accuracy | Peak episode reward: 18,007
- 🤖 Phase-based reward shaping · Tactile sensor integration (>90% accuracy across all 5 fingers)
- 🔬 Discovered and mitigated **reward hacking behaviour** during training
- 📄 **Published in IJRES Vol.13, Issue 6** · Co-author: Dr Diego Resende Faria
